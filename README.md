# 名鉄 運転士支援システム風 運行アプリ (MJ10029)

GitHub Pages でそのまま公開・動作する単一HTML構成のWebアプリケーションです。

## ファイル構成
- `index.html`: アプリ本体（CSS・JavaScript・PDF.js パーサー内蔵）
- `README.md`: GitHub Pages 公開手順書

## GitHub Pages への公開方法
1. GitHub で新しいリポジトリ（例: `meitetsu-timetable-app`）を作成します。
2. この ZIP ファイルを解凍し、中の `index.html` をリポジトリのルート直下にアップロード（コミット）します。
3. リポジトリの **Settings** → **Pages** を開きます。
4. **Build and deployment** の **Branch** で `main`（フォルダは `/ (root)`）を選択して **Save** を押します。
5. 数十秒〜1分ほどで公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行されます。

## 主な機能
- **実機レイアウト＆タイポグラフィ再現**: 丸ゴシック太字＋縦長均等割り付け駅名、上付き秒数、路線境界セパレータ（`外・名本` 等）、アナログ＆デジタル時計、記事欄を全列車に適用しています。
- **名鉄路線別時刻表 PDF 自動解析**: 画面上部の「📄 名鉄PDF解析 / 一覧」から名鉄公式の路線別時刻表PDFを選択すると、列車番号・種別・停車駅・発着時刻を自動抽出して登録します。
- **列車番号入力での即座切替**: 上部入力欄に列車番号（例: `778`, `1620S`, `1520S`, `370A`, `034` やPDFから抽出した列車番号）を入力して「適用」を押すとダイヤが切り替わります。
